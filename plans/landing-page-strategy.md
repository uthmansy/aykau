## 12. Design Guidelines

### Visual Style

- Clean, modern, professional
- Trust-building colors (navy, white, green accents)
- High-quality photos of real artisans
- Mobile-first responsive design
- Fast loading times

### Component Library

- Use existing Ant Design components
- Custom illustrations for key sections
- Consistent iconography (Material Symbols)
- Glassmorphism for elevated surfaces

### Accessibility

- WCAG 2.1 AA compliance
- Proper heading hierarchy
- Alt text for images
- Keyboard navigation
- Screen reader friendly
